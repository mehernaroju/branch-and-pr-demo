# branch-and-pr-demo

Practice the real GitHub workflow: **branch → change → pull request → merge**.

## What this teaches
- Creating a branch
- Making a change safely off `main`
- Opening a pull request (PR)
- Reviewing and merging

## Try it
1. Go to the Code tab → branch dropdown → type `practice/add-note` → Create branch
2. Edit `NOTES.md` on that branch and commit
3. Open a Pull Request into `main`
4. Merge the PR

## Why it matters
Teams almost never commit straight to `main`. PRs are how code gets reviewed and shipped.
